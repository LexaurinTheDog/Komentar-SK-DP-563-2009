# Komentár k zákonu č. 563/2009 Z. z., o správe daní (daňový poriadok)

Konsolidované znenie k **1. 9. 2026**, zdroj [slov-lex.sk](https://www.slov-lex.sk/static/SK/ZZ/2009/563/20260901.html).
